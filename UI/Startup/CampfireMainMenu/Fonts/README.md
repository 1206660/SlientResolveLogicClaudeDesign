# Startup Fonts

Place the licensed Startup menu font here:

```text
ZhongQiMaShanZhengBrushKai.ttf
```

This file is expected to be a licensed copy of 钟齐马善政毛笔楷书. The runtime screen uses it first for the title, subtitle, status text, and menu labels. If it is missing during editor preview, the code falls back to local Windows Kai fonts.
